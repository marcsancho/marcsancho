### 👋 Hi, I'm Marc

Front-end developer in Palma de Mallorca. Since 2023 I build large enterprise applications in
**Angular**, **React** and **ExtJS** at Serviceware, and I lead my team's move to **AI-first development**:
agents that plan, implement and review real tickets, with a person approving every write.

- 🧩 **Day job:** Angular widgets and apps in an NX monorepo, a very large ExtJS client, a React
  browser extension, Azure DevOps pipelines, Playwright and Jest.
- 🤖 **AI tooling:** a Claude Code plugin with agents, skills, MCP servers and guard hooks;
  OpenSpec as the single store of behaviour across repositories.
- 🚀 **Side project:** a multi-tenant SaaS for Spanish SMEs, in development — NestJS, Prisma,
  PostgreSQL, React, Railway and an agent-operated delivery pipeline.
- 🏕️ **Delivered:** a portable, offline desktop booking app for a summer camp (Next.js + Electron).
- 🎤 Every Serviceware Coding Convention since 2023, team hackathons and local dev conferences.
